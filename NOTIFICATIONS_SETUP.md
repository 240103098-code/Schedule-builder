# Telegram и email уведомления

## Подключить Telegram бесплатно

1. В Telegram откройте официальный @BotFather (https://t.me/BotFather).
2. Отправьте /newbot, задайте имя и username. Скопируйте выданный токен.
3. Остановите старый сервер (Ctrl+C). В папке проекта запустите:
   `.\start-with-telegram.ps1`
4. Введите токен только в локальном терминале. Он скрыт и не записывается в файл.
   Затем можно ввести Gmail и пароль приложения, чтобы включить почту одновременно.
   Альтернатива: TELEGRAM_BOT_TOKEN в .env, затем python main.py.
5. Войдите на сайт → Requests & Alerts → Подключить Telegram.
6. На телефоне откройте бота по ссылке или отсканируйте QR-код с экрана компьютера.
7. В личном чате нажмите Start. Сайт сам подтвердит подключение.
8. Выберите Telegram и подпишитесь на полную секцию. При освобождении места
   придёт сообщение с курсом и секцией. Для проверки есть кнопка учебного примера.

Привязка индивидуальная: одноразовая ссылка действует 10 минут.
Чужой username или chat_id вводить нельзя. Отключение отменяет ожидающие отправки.
Используйте отдельного бота для этого проекта, без webhook и других getUpdates-процессов.
Сервер должен работать, а на телефоне должны быть интернет и разрешённые уведомления Telegram.
Бесплатная отправка ботом имеет ограничения частоты; платные рассылки не включаются.
Статус «Отправлено в Telegram» означает принятие API, а не прочтение на телефоне.
При сетевом обрыве после приёма сообщения возможен дубль при повторной попытке.
Токен не публикуйте и не присылайте в чат. Для настройки не нужны карта или баланс SMS.

## Email через Gmail

1. Включите двухэтапную проверку Google и создайте пароль приложения:
   https://support.google.com/accounts/answer/185833
2. Перезапустите проект через .\start-with-telegram.ps1. Укажите токен бота,
   Gmail отправителя и пароль приложения. Пароли не пишутся в файл.
3. На сайте в разделе подписок нажмите «Отправить письмо для подтверждения адреса».
   Письмо придёт на адрес вашего аккаунта сайта; откройте его на компьютере,
   где запущен сайт, и подтвердите адрес по ссылке.
4. Вернитесь в подписки, выберите Email и сохраните подписку на полную секцию.
   Можно одновременно выбрать Telegram и Email.

Адрес аккаунта сайта должен быть реальным почтовым ящиком, к которому у вас есть доступ.
Отправитель может отличаться от получателя. APP_BASE_URL задаёт адрес для ссылок;
для стандартного localhost открывайте письмо на компьютере с запущенным сервером.
Если SMTP настроен в переменных окружения, скрипт использует существующие настройки.
Ошибки доставки остаются в очереди. SMTP-статус означает приём почтовым сервером.
