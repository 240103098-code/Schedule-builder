# Schedule Builder

Конструктор расписания на FastAPI с регистрацией, входом и восстановлением пароля по электронной почте.

## Запуск

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python main.py
```

После запуска откройте <http://127.0.0.1:8000>.

## Отправка писем для восстановления пароля

Приложение читает SMTP-настройки из переменных окружения. Пример значений находится в `.env.example`. Файл `.env` автоматически не загружается: задайте значения в окружении процесса или в настройках сервиса, на котором запускается приложение.

Пример для PowerShell:

```powershell
$env:APP_ENV = "production"
$env:APP_BASE_URL = "https://schedule.example.com"
$env:AUTH_COOKIE_SECURE = "true"
$env:SMTP_HOST = "smtp.example.com"
$env:SMTP_PORT = "587"
$env:SMTP_USERNAME = "no-reply@example.com"
$env:SMTP_PASSWORD = "your-app-password"
$env:SMTP_FROM = "no-reply@example.com"
$env:SMTP_USE_TLS = "true"
python main.py
```

SMTP необходим для регистрации, подтверждения почты, сброса пароля и уведомлений листа ожидания. Токены не выводятся в консоль и не возвращаются браузеру. Для запуска с Gmail используйте `./start-with-email.ps1`; подробности — в [EMAIL_SETUP.md](EMAIL_SETUP.md).

## Загрузка учебного плана

В разделе `Degree Progress` можно загрузить CSV или JSON размером до 5 МБ. Учебный план сохраняется для текущего аккаунта и автоматически отображается после следующего входа.

CSV должен содержать заголовки `category`, `code`, `name`, `credits`:

```csv
category,code,name,credits
Core Mathematics,MATH101,Calculus I,5
Computer Science Core,CS101,Intro to Programming,5
```

Также распознаются русские названия колонок: `категория`, `код`, `название`, `кредиты`. Готовый пример находится в `public/curriculum-template.csv` и доступен для скачивания прямо на сайте.

JSON может содержать массив дисциплин или структуру с категориями:

```json
{
  "name": "Computer Science 2026",
  "categories": [
    {
      "category": "Core",
      "required": [
        {"code": "CS101", "name": "Intro to Programming", "credits": 5}
      ]
    }
  ]
}
```

Также поддерживается расширенный каталог с корневыми массивами `subjects`, `electives` и `requisite_courses`. В этом формате обязательные дисциплины группируются по семестрам, варианты из `electives` показываются отдельными каталогами AE/NAE/NTE, а подготовительные курсы — разделом RC. Поля `ects`, `prerequisites`, `eligible_slots`, `recommended_semester`, `grade`, `completion_status`, `completed`, `in_progress` и `selected_in_curriculum` сохраняются и отображаются на сайте. Сводка `curriculum_progress` используется для общего прогресса по позициям и ECTS. Все эти данные сохраняются в аккаунте и восстанавливаются после повторного входа. Элективные варианты со статусом `not_selected` не прибавляются к числу незакрытых обязательных дисциплин.

## Мгновенная проверка пререквизитов

В карточке курса конструктора расписания укажите код дисциплины, например `INF 395`. Поле предлагает коды из загруженного учебного плана. Сайт немедленно сравнивает `prerequisites` выбранной дисциплины со статусами прохождения курсов:

- `completed` считается выполненным пререквизитом;
- `in_progress`, `available`, `planned` и неизвестный статус вызывают предупреждение;
- предполагаемые зависимости с `official: false` явно отмечаются в предупреждении;
- генерация расписания останавливается при любом невыполненном пререквизите, включая предполагаемый из загруженного файла.

Код выбранной дисциплины сохраняется вместе с расписанием пользователя.

## Безопасность

- Пароли хешируются через PBKDF2-SHA256 с индивидуальной солью.
- Сессии хранятся в `HttpOnly` cookie, а в базе находится только SHA-256-хеш токена.
- Ссылка сброса одноразовая, действует 30 минут и завершает все активные сессии пользователя после смены пароля.
- Курсы сохраняются отдельно для каждого аккаунта.
